# Agentic System: lezioni

Corsi in italiano per sviluppatori che usano già un coding agent. Spiegano i principi che rendono il lavoro di un agente **verificabile e correggibile**, usando come esempio un sistema di riferimento.

Il repository contiene due corsi, uno per ciascun sistema del kit. Scegli quello del sistema che usi o che vuoi conoscere.

| Corso | Sistema di riferimento | Stato |
| --- | --- | --- |
| **[Corso orchestrator](orchestrator/README.md)** | Un ruolo orchestrator guida il workflow scelto dallo sviluppatore (`DESIGN`, `FAST_IMPLEMENTATION`, `DOCUMENTATION`); un runtime locale serve le istruzioni una alla volta e custodisce sessioni, design e approvazione. | attuale |
| [Corso Planner/Implementor (legacy)](legacy/README.md) | Un Planner prepara un piano da approvare; un Implementor lo esegue in una nuova conversazione. I gate sono scritti nei contratti dei ruoli. | congelato: resta consultabile, non viene più aggiornato |

I sei principi sono gli stessi nei due corsi. Cambia il sistema che li mostra: se parti da zero, segui il corso orchestrator.
